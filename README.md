# Angie's Freebies

Birthday web game for Angelina.

## Play locally

```bash
npm install
npm run dev
```

## Live URL (GitHub Pages)

After you push to GitHub and Pages finishes deploying, the game will be at:

`https://<your-github-username>.github.io/angies-freebies/`

## Deploy again

Just push to `main`. GitHub Actions rebuilds and updates the site automatically.
